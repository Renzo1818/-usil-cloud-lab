Cloud Computing

Laboratorio: despliegue de una aplicación con Docker

Objetivo del laboratorio

Construir y publicar una página web dentro de un contenedor Docker utilizando herramientas accesibles desde el navegador.

Arquitectura del proyecto

1. IA generativa
2. HTML y CSS
3. Imagen Docker
4. Docker Hub
5. Nube pública

Proceso seguido

  1. Generación o edición del código web.
  2. Creación de un Dockerfile para empaquetar la página.
  3. Construcción de la imagen y publicación en Docker Hub.
  4. Despliegue del contenedor en una plataforma cloud.
  5. Validación mediante una URL HTTPS pública.

Conceptos aprendidos

Contenedores, imágenes, registro de imágenes, despliegue, escalabilidad y publicación de aplicaciones web.
